# Menu recolhível

Base: SpineViewer-Android-Spine42-Textured-Experimental(2).zip.

A tela inicia com o menu de importação e configurações fechado. Toque em "☰ Opções" para mostrar ou esconder seleção de pasta, importações, carregamento do runtime, escolha de renderizador e diagnóstico Vulkan. A visualização do personagem fica acima dos controles de skins e animações. Não há mudanças nos runtimes Spine 4.1/4.2 ou nos renderizadores.

Compilação Android não executada neste ambiente.
